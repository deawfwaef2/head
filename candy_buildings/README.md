# 糖果收纳建筑包（16 座）

独立的设计与数据文件，**不接入任何游戏接口**，可以直接拿到别的项目里用。

- `buildings.js`：16 座建筑的数据。字段沿用原项目写法：`cat / n / icon / base / grow / fp / stat / depth / showcase / desc / mount.slots`。另外三个字段：
  - `mech`：机制参数，和引擎无关，移植时按 `type` 实现；
  - `fx`：反馈表现；
  - `E`：空手按 E 时的互动。
- 放置物：**球体**，比如糖球、玻璃珠、扭蛋、彩蛋。每颗球有四个属性：`color`（色相 0–360）、`size`、`clarity`（透明度 0–1）、`rarity`（0–4）。
- 加载方式：`<script src="buildings.js">` 后可用 `window.CANDY_BUILDINGS`；在 Node 里用 `require()` 也行。

## 设计目标：观赏感、舒适感、收纳感

收纳类玩法让人舒服，主要靠下面这些感受，每座建筑至少主打其中两种：

| 感受 | 为什么舒服 | 主打建筑 |
|---|---|---|
| **从乱到整** | 东西归位、排整齐，会有“事情办完了”的轻松感 | 蛋托收纳盒、分拣传送带、珠算盘 |
| **刚刚好** | 严丝合缝的“咔哒”声和吸附感很解压 | 蛋托收纳盒、像素地毯、深框展盒 |
| **颜色和谐** | 渐变、彩虹、对称本身就好看 | 渐变糖罐墙、阳光窗台、糖珠门帘 |
| **差一点就齐** | 只差一个的套装会让人一直惦记，补齐时特别满足 | 像素地毯、渐变糖罐墙、蛋托收纳盒 |
| **看它自己动** | 循环、规律的运动有催眠般的放松效果 | 螺旋弹珠滚道、分拣传送带、灯笼串光流 |
| **看得见的成长** | 房间一天比一天漂亮、东西越堆越多 | 糖果树、彩虹球池、糖霜拱门 |
| **作品感** | 自己摆出来的东西被认可、被留下 | 深框展盒、像素地毯、糖果小铺 |
| **小惊喜** | 不确定的奖励让人期待下一次 | 扭蛋机、糖果小铺的特别客人、黄金时刻 |
| **掌控感** | 自己调整就能变得更好，而且没有失败惩罚 | 棉花糖天平、阳光窗台、灯笼串 |

### 反馈原则（舒适向，不是刺激向）

1. **软**：多用玻璃轻碰、木头“嗒”、铃铛、风铃这类声音，不用爆炸、重低音和强震屏。
2. **奖励先看得见**：房间先变漂亮（光斑、灯、花纹、外观升级），数字其次。
3. **慢一点**：大事件给 0.3–0.6 秒的预备，比如罐子逐个亮起、扭蛋停顿后再打开，再给结果。
4. **不惩罚**：没有失败状态。摆得不好只是加成少，随时可以重来。
5. **不刷屏**：同类飘字 0.3 秒内只出一次，循环类建筑的音效要降低音量并随机化音高。

| 13 | 糖果小铺 | `visitors` | 可爱的居民来逛，满足心愿给小费；口碑高了来特别的客人 | 作品感、小惊喜 |
| 14 | 深框展盒 | `composition` | 按三分法、对称、配色、留白给构图打分，签名定稿成作品 | 作品感、颜色和谐 |

每座建筑的完整数值（周期、倍率、上限、槽位坐标、反馈细节）写在 `buildings.js` 对应条目里。

## 和原项目不重复

原项目里已有的机制，这里都没有再用：
- 桌面连锁、定时插杆、定时展示台、旋转转盘、音箱光环
- 开柜巡礼、吊灯摇摆连锁、博古架多米诺、镜子加成
- 胸像/石像嫁接、花瓶酿造、液体浸泡、冰窖存量加成
- 夹具、转椅、摆钟、发射、飞镖靶、蒸馏、八音盒合唱
- 床、梳妆台、王座、祭坛、火盆、悬赏榜

新机制包括色彩排序、平衡、生长、自动分拣、光影连线、穿行触发、像素图案、进位、堆积深度、闭环拓扑、访客心愿、构图评分、扭蛋保底、里程碑进化。

## 移植提示

- **`stat`**：`comfort`（舒适）和 `view`（观赏）换成目标项目自己的属性名就行。
- **`mount.slots`**：坐标是 `[x, y, z, yaw]`，单位米，相对建筑原点（地面中心）。下面三项是额外位置表：
  - `growSlots`：糖果树后长出来的位置；
  - `bins`：分拣传送带的四个箱子；
  - `loose`：球池的散放区域。
- **`every`**：单位是秒，表示每隔多少秒触发一次；`mul` / `maxMul` 是乘在单颗基础产出上的倍率。
- **最省事的移植顺序**：
  1. 先做纯摆放类：蛋托、糖罐墙、像素地毯、展盒；
  2. 再做定时类：天平、窗台、糖果树、球池、拱门；
  3. 最后做带动画或 NPC 的：滚道、传送带、珠帘、算盘、灯笼串、小铺、扭蛋机。
